v0.1.0

2026-11-20 · First release
  • Three step setup: what to sync, the repo, this computer's folder.
  • Push and Pull buttons, with the background lines flowing right for Push and left for Pull, and a SYNCED notice when they land.
  • Live sync switch with Live settings: settings, widgets, themes, connections and AI modes go live; workspaces, tabs and layouts wait for Push, with a rate limit warning if you turn them on.
  • Profiles: one folder per computer, apply any of them, choose where future changes go, with a backup first.
  • Widgets bring their tools: git repos and build steps, Homebrew, npm, cargo and small scripts are found and installed.
  • GitHub sign in with a device code, or guest mode on a public repo with this computer's git login.
  • Secrets stripped before anything leaves; the home folder is stored as {HOME}.
  • Command line: --sync, --pull, --profiles, --apply, --detect, --setup.
  • Builds for macOS (Apple silicon and Intel), Windows and Linux.
  • Üç adımlı kurulum: ne senkronlansın, depo, bu bilgisayarın klasörü.
  • Push ve Pull butonları: Push'ta arka plan çizgileri sağa, Pull'da sola akar; iş bitince SYNCED bildirimi çıkar.
  • Canlı senkron anahtarı ve Canlı ayarlar: ayarlar, widget'lar, temalar, bağlantılar ve AI modları canlı gider; çalışma alanları, sekmeler ve düzenler Push'u bekler, açmak istersen hız limiti uyarısı çıkar.
  • Profiller: her bilgisayara bir klasör, herhangi birini uygula, değişikliklerin nereye gideceğini seç; önce yedek alınır.
  • Widget'lar araçlarıyla gelir: git depoları ve derleme adımları, Homebrew, npm, cargo ve küçük betikler bulunur ve kurulur.
  • Cihaz koduyla GitHub girişi ya da bu bilgisayarın git girişiyle public bir depoda misafir modu.
  • Bir şey çıkmadan önce gizli bilgiler ayıklanır; ev klasörü {HOME} olarak saklanır.
  • Komut satırı: --sync, --pull, --profiles, --apply, --detect, --setup.
  • macOS (Apple silicon ve Intel), Windows ve Linux için derlemeler.
