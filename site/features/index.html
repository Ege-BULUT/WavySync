Features

Everything Wavy~Sync does

One small Rust app that keeps Wave Terminal the same on every computer you use.

PUSH · PULL

Push and Pull

Push sends this Wave to its folder in the repo, layouts included, and the lines in the window flow to the right. Pull brings the folder back into Wave and the lines flow to the left. When either one lands, a green SYNCED shows for a moment. Pull closes Wave only when the layouts actually differ.

LIVE

Live sync, without the noise

Turn the live sync switch on and a background process sends settings, widgets, themes and connections as they change. Workspaces, tabs and layouts change with every pane you move, so they wait for Push unless you turn them on in Live settings, and WavySync warns you about GitHub's rate limits before you do.

WIDGETS

Widgets bring their tools

WavySync reads each widget and finds what it runs: a git repo and its build steps, a Homebrew formula, a global npm package, a cargo install, or a small script it carries along. Applying a profile installs them on the other computer.

PROFILES

One folder per computer, any profile anywhere

Each computer saves to its own folder, named after the computer, and you can rename it. Apply another computer's profile and choose where your future changes go: your own folder, the profile you applied, or a new one. Your current Wave is backed up first.

REPO

Your repo, private or public

Sign in with GitHub to pick or create a private repo, or use a public repo as a guest with this computer's own git login. Keys, tokens and passwords are stripped before anything leaves, and your home folder is stored as {HOME} so paths work under another user name.

Tokens, keys and passwords are stripped. Your home folder becomes {HOME}.

NATIVE

Small Rust app

One binary for macOS, Windows and Linux, drawn with Rune, plus a widget in Wave's sidebar.

Never leaves your computer

  • Keys named like token, secret, password, apikey, privatekey
  • Terminal history and scrollback
  • Your GitHub sign in: it stays in the system keychain
  • Anything you leave unticked
