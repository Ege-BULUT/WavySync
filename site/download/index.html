Get Wavy~Sync.

One file per system. Run it and the three step setup opens.

Latest release: v0.1.0 · Changelog · All releases

Before you start

  • git must be on your PATH.
  • Wave Terminal does not have to be installed when you apply a profile; WavySync writes the files where Wave will read them. Get Wave from its latest release or waveterm.dev/download.
  • The binaries are not signed yet.

macOS

tar -xzf wavysync-macos-arm64.tar.gz     # or wavysync-macos-x64.tar.gz on Intel
xattr -d com.apple.quarantine ./wavysync
./wavysync

Windows

Run wavysync-windows-x64.exe. SmartScreen may warn about an unknown publisher: choose More info, then Run anyway.

Linux

tar -xzf wavysync-linux-x64.tar.gz
./wavysync

Build from source

Current stable Rust; on Linux also libxkbcommon-dev and libwayland-dev.

git clone https://github.com/Ege-BULUT/WavySync
cd WavySync
cargo build --release
./target/release/wavysync

Başlamadan önce

  • git PATH üzerinde olmalı.
  • Profil uygularken Wave Terminal'in kurulu olması gerekmez; WavySync dosyaları Wave'in okuyacağı yere yazar. Wave'i son sürümünden ya da waveterm.dev/download adresinden indirebilirsin.
  • Dosyalar henüz imzalı değil.

macOS

tar -xzf wavysync-macos-arm64.tar.gz     # Intel'de wavysync-macos-x64.tar.gz
xattr -d com.apple.quarantine ./wavysync
./wavysync

Windows

wavysync-windows-x64.exe dosyasını çalıştır. SmartScreen bilinmeyen yayıncı uyarısı verirse Ek bilgi, sonra Yine de çalıştır de.

Linux

tar -xzf wavysync-linux-x64.tar.gz
./wavysync
