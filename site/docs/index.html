Getting started

WavySync keeps Wave Terminal the same on every computer through a GitHub repo you own. Each computer writes to its own folder in that repo, and any computer can take on another's setup. Download it, run it, and the setup opens.

Setup

The first run opens three steps:

  1. 01 Sync: tick what should travel: settings, workspaces and layouts, widgets and extensions (each widget has its own box), themes, connections, AI modes.
  2. 02 Repo: sign in with GitHub to pick or create a repo, or paste a public repo to use guest mode with this computer's own git login.
  3. 03 Profile: name this computer's folder (it starts as the computer's id) and, if you like, apply another computer's profile.

When setup finishes, WavySync adds a WavySync widget to Wave's sidebar and a background process to your login items.

Push and Pull

Push reads Wave's config files and its workspace database (read only), removes secrets and local noise, and commits what changed to this computer's folder. Layouts are included.

Pull writes this computer's folder from the repo back into Wave. If the incoming workspaces and layouts are the same as what Wave has, Wave keeps running; if they differ, Wave is asked to quit, the files are written and Wave starts again. Confirm Wave's question if it shows one.

Your current Wave is backed up before anything is written.

Live sync

With the live sync switch on, the background process checks every 30 seconds and pushes the items marked live in Live settings. Everything else in the folder stays as the last Push left it.

ItemLive by default
SettingsYes
Widgets and extensionsYes
Themes, presets, backgroundsYes
Connections (SSH)Yes
AI modesYes
Workspaces, tabs, layoutsNo: Push only

Workspaces, tabs and layouts change every time you move a pane or open a tab. Syncing them live sends a commit for nearly every change, which can hit GitHub's rate limits fast, so the recommended way is to send them with Push when you need to.

Apply a profile

Pick a profile (any computer's folder) and choose where this computer's future changes are saved: its own folder, the profile you just applied (you will be warned that it gets overwritten), or a new folder. WavySync then:

  1. backs up the current Wave to ~/.config/wavysync/backups,
  2. asks Wave to quit,
  3. writes the profile and installs what its widgets need,
  4. starts Wave again and pushes to the folder you chose from then on.

The repo

your-wave-profiles/                 a GitHub repo you own
├── studio-mac-7f3a/                one folder per computer
│   ├── wavysync.json               host, system, last update
│   ├── config/                     settings.json, widgets.json, themes, presets, connections
│   ├── workspaces.json             workspaces, tabs, blocks, layouts
│   ├── extensions.json             what each widget needs, and how to install it
│   └── files/                      small scripts widgets run, kept under {HOME}
├── work-imac-2c91/
└── ubuntu-lab-04be/

All plain files. Your home folder is stored as {HOME} so paths work under a different user name.

What stays private

  • Keys whose name contains token, secret, password, passwd, apikey, api_key or privatekey.
  • Wave's terminal history and scrollback.
  • WavySync's own GitHub sign in, kept in the system keychain.
  • Anything you leave unticked.

Command line

wavysync                 open the window
wavysync --sync          push now, everything picked
wavysync --pull          bring this computer's folder from the repo into Wave
wavysync --profiles      list the profiles in the repo
wavysync --apply NAME [--save-to FOLDER]
                         set this Wave to profile NAME
wavysync --detect        print the widgets found and what each needs
wavysync --setup REPO [--folder NAME] [--guest]
                         set up without the window

Files and settings

~/.config/wavysync/config.jsonWavySync's settings. WAVYSYNC_HOME moves the folder.
~/.config/wavysync/backupsA backup of Wave before each apply or pull.
WAVETERM_CONFIG_HOME, WAVETERM_DATA_HOMEFollowed when set, the same way Wave does.

Uninstall

  1. Remove the background process from your login items: on macOS ~/Library/LaunchAgents/app.wavysync.plist, on Windows the WavySync value under HKCU\Software\Microsoft\Windows\CurrentVersion\Run, on Linux ~/.config/autostart/wavysync.desktop.
  2. Remove the wavysync entry from Wave's widgets.json, or from Wave's widget settings.
  3. Delete ~/.config/wavysync and the binary. Your repo stays on GitHub.

Troubleshooting

macOS says the app is damaged or from an unknown developer

The binaries are not signed yet. Run xattr -d com.apple.quarantine ./wavysync once.

macOS asks for keychain access

The GitHub sign in lives in the keychain. A new build is a new binary to macOS, so it asks again after an update. Choose Always Allow.

Wave shows a quit question during Pull or Apply

That is Wave confirming it may close. Confirm it; WavySync writes the files and starts Wave again.

Something did not come across

Check it is ticked in step 01 and, for live sync, in Live settings. If it still does not travel, open an issue.

Başlangıç

WavySync, senin GitHub deponla Wave Terminal'i her bilgisayarda aynı tutar. Her bilgisayar o depoda kendi klasörüne yazar ve herhangi bir bilgisayar bir başkasının düzenini alabilir. İndir, çalıştır; kurulum açılır.

Kurulum

İlk açılışta üç adım gelir:

  1. 01 Sync: neyin taşınacağını işaretle: ayarlar, çalışma alanları ve düzenler, widget'lar ve eklentiler (her widget'ın kendi kutusu var), temalar, bağlantılar, AI modları.
  2. 02 Repo: GitHub ile giriş yapıp bir depo seç ya da oluştur, ya da misafir modunda bu bilgisayarın kendi git girişiyle kullanmak için public bir depo yapıştır.
  3. 03 Profile: bu bilgisayarın klasörüne ad ver (bilgisayarın kimliğiyle başlar) ve istersen başka bir bilgisayarın profilini uygula.

Kurulum bitince WavySync, Wave'in kenar çubuğuna bir WavySync widget'ı ve oturum açılışına bir arka plan süreci ekler.

Push ve Pull

Push, Wave'in ayar dosyalarını ve çalışma alanı veritabanını okur (yalnızca okur), gizli bilgileri ve yerel gürültüyü ayıklar ve değişeni bu bilgisayarın klasörüne commit eder. Düzenler dahildir.

Pull, bu bilgisayarın depodaki klasörünü Wave'e geri yazar. Gelen çalışma alanları ve düzenler Wave'dekiyle aynıysa Wave açık kalır; farklıysa Wave'in kapanması istenir, dosyalar yazılır ve Wave yeniden açılır. Wave soru sorarsa onayla.

Bir şey yazılmadan önce mevcut Wave'in yedeklenir.

Canlı senkron

Canlı senkron anahtarı açıkken arka plan süreci 30 saniyede bir bakar ve Canlı ayarlar'da canlı işaretli öğeleri gönderir. Klasördeki diğer her şey son Push'taki haliyle kalır.

ÖğeVarsayılan olarak canlı
AyarlarEvet
Widget'lar ve eklentilerEvet
Temalar, ön ayarlar, arka planlarEvet
Bağlantılar (SSH)Evet
AI modlarıEvet
Çalışma alanları, sekmeler, düzenlerHayır: sadece Push

Çalışma alanları, sekmeler ve düzenler her bölme taşıdığında ya da sekme açtığında değişir. Bunları canlı göndermek neredeyse her değişiklikte bir commit demek ve GitHub'ın hız limitleri çabuk dolabilir. Önerilen yol, bunları gerektiğinde Push ile göndermek.

Profil uygulama

Bir profil (herhangi bir bilgisayarın klasörü) seç ve bu bilgisayarın ileride yapacağı değişikliklerin nereye kaydedileceğini belirle: kendi klasörü, az önce uyguladığın profil (üzerine yazılacağı konusunda uyarılırsın) ya da yeni bir klasör. Sonra WavySync:

  1. mevcut Wave'i ~/.config/wavysync/backups klasörüne yedekler,
  2. Wave'in kapanmasını ister,
  3. profili yazar ve widget'larının ihtiyaç duyduklarını kurar,
  4. Wave'i yeniden açar ve bundan sonra seçtiğin klasöre gönderir.

Depo

your-wave-profiles/                 senin GitHub deponun
├── studio-mac-7f3a/                her bilgisayara bir klasör
│   ├── wavysync.json               makine, sistem, son güncelleme
│   ├── config/                     settings.json, widgets.json, temalar, ön ayarlar, bağlantılar
│   ├── workspaces.json             çalışma alanları, sekmeler, bloklar, düzenler
│   ├── extensions.json             her widget'ın neye ihtiyacı olduğu ve nasıl kurulacağı
│   └── files/                      widget'ların çalıştırdığı küçük betikler, {HOME} altında
├── work-imac-2c91/
└── ubuntu-lab-04be/

Hepsi düz dosya. Ev klasörün {HOME} olarak saklanır; böylece yollar başka bir kullanıcı adında da çalışır.

Gizli kalanlar

  • Adında token, secret, password, passwd, apikey, api_key ya da privatekey geçen anahtarlar.
  • Wave'in terminal geçmişi ve kaydırma arabelleği.
  • WavySync'in kendi GitHub girişi; sistem anahtar zincirinde kalır.
  • İşaretlemediğin her şey.

Dosyalar ve ayarlar

Kaldırma

  1. Arka plan sürecini oturum açılışından kaldır: macOS'ta ~/Library/LaunchAgents/app.wavysync.plist, Windows'ta HKCU\Software\Microsoft\Windows\CurrentVersion\Run altındaki WavySync değeri, Linux'ta ~/.config/autostart/wavysync.desktop.
  2. Wave'in widgets.json dosyasından ya da widget ayarlarından wavysync girdisini sil.
  3. ~/.config/wavysync klasörünü ve programı sil. Deponun GitHub'da kalır.

Sorun giderme

macOS uygulamanın hasarlı ya da bilinmeyen bir geliştiriciden olduğunu söylüyor

Dosyalar henüz imzalı değil. Bir kez xattr -d com.apple.quarantine ./wavysync çalıştır.

macOS anahtar zinciri izni istiyor

GitHub girişi anahtar zincirinde durur. Yeni bir derleme macOS için yeni bir programdır, bu yüzden güncellemeden sonra yeniden sorar. Her Zaman İzin Ver'i seç.

Pull ya da Uygula sırasında Wave kapatma sorusu soruyor

Bu, Wave'in kapanabileceğini onaylamasıdır. Onayla; WavySync dosyaları yazar ve Wave'i yeniden açar.

Bir şey gelmedi

01. adımda, canlı senkron içinse Canlı ayarlar'da işaretli olduğuna bak. Yine gelmiyorsa bir issue aç.
